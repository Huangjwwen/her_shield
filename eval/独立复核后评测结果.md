# 独立复核后评测结果

## 评测口径

第 101-1000 条 F-Q 要件已重新独立复核。复核仅使用案例 `input`、要件级人工标注指南和 `risk_level.py`，未调用此前提供的智能体，也未读取其结构化要件输出。`agent_result` 在标准答案生成前保持隔离，仅在 `final_level` 计算完成后用于比较。

评测链路如下：

```text
input → 独立复核 F-Q → risk_level.py → final_level → 对比 agent_result
```

“无关”在等级统计时按“无风险”归一。

## 主要发现

1. 旧报告中的 96.5% 是同源要件与智能体等级的内部一致率，独立复核后下降至 76.3%，确认此前结果明显虚高。
2. 高危召回率为 82.0%，共有 90 条高危被低估，其中 42 条被判为低危，应优先复核和优化。
3. 中危区分能力最弱：44 条被升为高危、25 条被降为低危，反映边界判断不稳定。
4. 智能体没有把任何样本直接输出为“无风险”以外的空值；但有 44 条标准无风险样本被判为中危或低危，存在过度预警。
5. 变体准确率略高于扩展基础案例，说明该结果不能简单解释为变体更难；更可能与不同事实模式在两组中的分布有关。

## 限制

本轮属于一次独立规则复核，消除了被测智能体输出直接参与答案构造的问题，但尚未完成双人盲标和分歧仲裁。因此 76.3% 可作为当前内部评测结果；若用于正式答辩或外部发布，仍建议抽取高危降级、无风险误报和中危边界样本进行第二标注者复核。
