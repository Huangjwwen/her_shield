## ⭐ 10 分钟版精简大纲(主推 · 13 页)

10 分钟 = 演讲 7-8 分钟 + 现场演示 1-2 分钟 + Q&A 1-2 分钟。每页平均 **35-40 秒**,**禁止任何"过场页"**(章节封面/纯标题页/致谢页全部砍掉)。

### 13 页结构(每页停留时间已标)

| # | 页面 | 时长 | 一页只讲一件事 |
|---|------|------|----------------|
| **P1** | **封面** | 5s | 项目名 + 一句宣言"你的身后,站着一个懂法更懂你的「她」" |
| **P2** | **痛点数据 + 五层断裂链** | 50s | 三个核心数字(60.9%/30%/7%)+ 一张五层垂直分层图 |
| **P3** | **差异化 4×6 对比表** | 30s | 通用法律/女性社区/法律援助/**她盾**,她盾这一行 6 个 ✓ 全部高亮 |
| **P4** | **6 大模块总览**(2×3 网格)| 40s | 每个卡片只放图标 + 名称 + 一句话定位 |
| **P5** | **端到端技术架构图** ⭐⭐⭐ | 60s(停足) | **必须让评委看见"得理 API"那个框** —— 直接回应专家1批评 |
| **P6** | **言行雷达工作流深度**(图+5节点) | 60s | 重点标出"代码节点确定性映射" → 答辩话术"等级由规则裁定,不是 AI 主观打分" |
| **P7** | **风险分级准则 + 反误判机制** ⭐ | 50s | 四级触发规则表 + 反误判按钮截图,一页讲完"可解释 + 用户底线保障" |
| **P8** | **100 条测试集方法学** ⭐⭐⭐ | 45s | 50 精标 + 50 变体 + 17 条真实判例锚点 + 5 类变体策略 |
| **P9** | **准确率 + 混淆矩阵** ⭐⭐⭐ | 45s | 大数字"准确率 XX%(95% CI ±7%)"+ 4×4 热力图 |
| **P10** | **真实判例锚定**(3 个) | 30s | 严女士案 / 韩坤案 / 周某案 — 案号 + 法院 + 判决结果展示 |
| **P11** | **现场演示**(婚育询问案例) | 90s | 实时跑一次:输入→风险标→法条→话术→"得理"徽标。**有备用截图** |
| **P12** | **评委预期质疑回应**(3 条最关键) | 40s | 表格:得理可见 / 技术深度 / 测试集准确性 — 每条一句话回应 |
| **P13** | **社会价值 + 致谢**(合并) | 25s | "降低三道门槛 → 从'算了吧'到'我知道该怎么做了'"+ 工具致谢一行 |

**总演讲时间:约 8 分 30 秒,留 1.5 分钟给 Q&A 和缓冲。**

### 10 分钟版相比完整版砍了什么

| 砍掉的页 | 原因 | 替代方式 |
|---|---|---|
| ❌ 五步递进图(P5 原) | 与"6 模块总览"信息重复 | 模块图自带顺序感 |
| ❌ 核心创新点单独页(P7 原) | 不如直接用"得理可见"的架构图证明深度 | 合到 P5 架构图讲 |
| ❌ 关键技术细节(P12 原) | SHA-256/危机干预不是答辩主战场 | 一句话口头带过,放 Q&A 抽屉里 |
| ❌ 鲁棒性单独页(P15 原) | 与准确率合并展示 | 准确率页右下角加一个"5 类变体 X% 通过" |
| ❌ 三场景演示截图(P17 原) | 现场跑一次更有冲击力 | P11 现场演示页保留 1 个最强场景 |
| ❌ 技术人文主义(P19 原) | 抒情段落口头讲更打动人 | 移到 P13 社会价值口头收尾 |
| ❌ "还想做的"(P21 原) | 答辩不主动暴露弱点 | Q&A 被问到才说 |
| ❌ 致谢独立页 + Q&A 页 | 浪费时间 | 致谢压到 P13 角落,Q&A 不需要专页 |

### 10 分钟版的"必演示"清单

- **架构图必须停 30 秒**——让评委亲眼看到得理那个节点
- **现场演示必须真跑通**——准备好 3 个测试输入,选最快出结果的那个
  - 推荐输入:"面试 HR 问我打算什么时候结婚生孩子"(已验证返回中危,2-3 秒)
  - 备用截图:同样输入的完整结果截图,网络出问题时直接放图
- **大数字必须飞出来**——准确率、95% CI、判例数,字号 60pt+

## 二、字体与版式

### 2.1 字体

- **标题**:思源宋体(Noto Serif SC,网页同款)700/600,体现"法律 + 温度"的庄重感
- **正文**:思源黑体(Source Han Sans) / 微软雅黑 400/500,清晰易读
- **代码块/数字**:JetBrains Mono / Consolas

### 2.2 版式原则

- **大留白**:每页主信息占视觉中心 60% 以内,周围留白,避免堆砌
- **左对齐为主**:正文严格左对齐,标题居左,只有标题页 + 章节封面用居中
- **图标 + 关键词 + 一句话**:每个要点不超过一句话,搭配 emoji 或简洁图标
- **配色克制**:每页主色块最多 1-2 个,其他用中性色

### 第一章 · 为什么做(2-3 页)

**P2 痛点 - 一句话开场**
> "60.9% 的求职女性被问婚育情况,职场歧视案胜诉率不足 30%,7% 受害者最终选择报警。"
- 三个核心数字大字号居中
- 来源标注:智联招聘 2026 / 中国裁判文书网 / 全国妇联

**P3 五层断裂链**
- 一个垂直分层图:认知层 → 情绪层 → 证据层 → 行动层 → 归属层
- 每层一句话标注用户的困境(不知违法 / 不知找谁 / 不会取证 / 不敢维权 / 孤立无援)
- 配色:从上到下用暖紫的浅→深,视觉上"断"

**P4 我们的定位(差异化)**
- 一张 4×6 表格:对比"通用法律咨询/女性社区/传统法律援助/她盾"在 6 维度的覆盖
- 她盾这一行全部 ✓,用主色高亮整行

---

### 第二章 · 怎么做(6-8 页) ⭐ 核心

**P5 解决方案 - 五步递进**
> 情绪承接 → 认知赋能 → 证据固化 → 行动指引 → 社群支持
- 水平五个圆形节点,中间用浅紫线串联
- 每个节点配对应模块的图标和名称

**P6 6 大功能模块总览**
- 2×3 卡片网格,每个卡片左边 4px 紫色边线
- 卡片内:模块图标 + 名称 + 一句话定位
- 她眼/她权/她证/她行/她心/她声

**P7 核心创新点(差异化亮点)** ⭐⭐⭐
- 标题:**法律能力 × AI 效率 × 情绪承接 的融合型智能体**
- 三个并列亮点框:
  - 🧠 认知辅助 — 接管复杂法律逻辑分析
  - 🧭 行动引导 — 把抽象维权路径拆成"下一步做什么"
  - 💖 心理缓冲 — 用共情交互让用户"背后有人"

**P8 技术架构图**
- 端到端架构:用户 → 前端(GitHub Pages,HTML5+CSS3+JS)→ CloudBase 代理(密钥下沉 + 缓存)→ 元器 5 大智能体 → 得理 API(法规 + 类案)
- 重点标注"得理 API"——这是回应专家1"得理 API 空声明"批评的关键
- 配色:每层用暖紫不同明度的色块
- 这一页必须放,**让评委亲眼看到得理在哪**

**P9 言行雷达工作流(核心模块深度展示)** ⭐⭐⭐
- 把元器工作流截图放在左半,右半文字说明 5 个关键节点
- 标出:① 召回优先门控 ② 案情要素抽取 ③ 法规+类案并行检索 ④ 要件式判定 ⑤ **代码节点确定性等级映射**
- 答辩话术:"等级由规则引擎裁定,不是 AI 主观打分"

**P10 风险分级准则(可解释性) ⭐⭐⭐**
- 大表格:四级等级(🔴高危/🟠中危/🟡低危/🟢无风险)× 触发条件
- 强调"按法律要件 + 加重情节按规则映射,可追溯、同问同答"
- 这一页直接回应专家2的"技术深度不足"

**P11 反误判机制(产品判断力)**
- 截图:用户被门控判"不涉及"时,弹出"强制深度分析"按钮
- 解释:"召回优先 + 用户可一键推翻",这是对求助者的底线保障
- 答辩亮点:"即使算法犯错,用户也有发言权"

## 六、做 PPT 时的"避雷清单"

1. ❌ **别用纯黑底**:暖紫主题撑不住黑底,会显得阴沉
2. ❌ **别堆术语**:技术页里"要件""召回优先"这些词,**每页最多出现一次**,其他用白话
3. ❌ **别用红配绿对比**:用我们定的"风险等级配色"是合法的,但其他地方不要乱配
4. ❌ **别让单页超过 7 个要点**:超过就拆页
5. ❌ **代码截图字号要够大**:演示页代码 18pt 以上,远的评委看得见
6. ✅ **每页有一个明确的"视觉焦点"**:大数字 / 大图 / 大引用 选一个,不要混搭
7. ✅ **现场演示有备用截图**:网络抽风时切回截图,别白屏
