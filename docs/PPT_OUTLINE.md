## 二、字体与版式

### 2.1 字体

- **标题**:思源宋体(Noto Serif SC,网页同款)700/600,体现"法律 + 温度"的庄重感
- **正文**:思源黑体(Source Han Sans) / 微软雅黑 400/500,清晰易读
- **代码块/数字**:JetBrains Mono / Consolas

### 2.2 版式原则

- **大留白**:每页主信息占视觉中心 60% 以内,周围留白,避免堆砌
- **左对齐为主**:正文严格左对齐,标题居左,只有标题页 + 章节封面用居中
- **图标 + 关键词 + 一句话**:每个要点不超过一句话,搭配 emoji 或简洁图标
- **配色克制**:每页主色块最多 1-2 个,其他用中性色

### 第一章 · 为什么做(2-3 页)

**P2 痛点 - 一句话开场**
> "60.9% 的求职女性被问婚育情况,职场歧视案胜诉率不足 30%,7% 受害者最终选择报警。"
- 三个核心数字大字号居中
- 来源标注:智联招聘 2026 / 中国裁判文书网 / 全国妇联

**P3 五层断裂链**
- 一个垂直分层图:认知层 → 情绪层 → 证据层 → 行动层 → 归属层
- 每层一句话标注用户的困境(不知违法 / 不知找谁 / 不会取证 / 不敢维权 / 孤立无援)
- 配色:从上到下用暖紫的浅→深,视觉上"断"

**P4 我们的定位(差异化)**
- 一张 4×6 表格:对比"通用法律咨询/女性社区/传统法律援助/她盾"在 6 维度的覆盖
- 她盾这一行全部 ✓,用主色高亮整行

### 第二章 · 怎么做(6-8 页) ⭐ 核心

**P5 解决方案 - 五步递进**
> 情绪承接 → 认知赋能 → 证据固化 → 行动指引 → 社群支持
- 水平五个圆形节点,中间用浅紫线串联
- 每个节点配对应模块的图标和名称

**P6 6 大功能模块总览**
- 2×3 卡片网格,每个卡片左边 4px 紫色边线
- 卡片内:模块图标 + 名称 + 一句话定位
- 她眼/她权/她证/她行/她心/她声

**P7 核心创新点(差异化亮点)** ⭐⭐⭐
- 标题:**法律能力 × AI 效率 × 情绪承接 的融合型智能体**
- 三个并列亮点框:
  - 🧠 认知辅助 — 接管复杂法律逻辑分析
  - 🧭 行动引导 — 把抽象维权路径拆成"下一步做什么"
  - 💖 心理缓冲 — 用共情交互让用户"背后有人"

**P8 技术架构图**
- 端到端架构:用户 → 前端(GitHub Pages,HTML5+CSS3+JS)→ CloudBase 代理(密钥下沉 + 缓存)→ 元器 5 大智能体 → 得理 API(法规 + 类案)
- 重点标注"得理 API"——这是回应专家1"得理 API 空声明"批评的关键
- 配色:每层用暖紫不同明度的色块
- 这一页必须放,**让评委亲眼看到得理在哪**

**P9 言行雷达工作流(核心模块深度展示)** ⭐⭐⭐
- 把元器工作流截图放在左半,右半文字说明 5 个关键节点
- 标出:① 召回优先门控 ② 案情要素抽取 ③ 法规+类案并行检索 ④ 要件式判定 ⑤ **代码节点确定性等级映射**
- 答辩话术:"等级由规则引擎裁定,不是 AI 主观打分"

**P10 风险分级准则(可解释性) ⭐⭐⭐**
- 大表格:四级等级(🔴高危/🟠中危/🟡低危/🟢无风险)× 触发条件
- 强调"按法律要件 + 加重情节按规则映射,可追溯、同问同答"
- 这一页直接回应专家2的"技术深度不足"

**P11 反误判机制(产品判断力)**
- 截图:用户被门控判"不涉及"时,弹出"强制深度分析"按钮
- 解释:"召回优先 + 用户可一键推翻",这是对求助者的底线保障
- 答辩亮点:"即使算法犯错,用户也有发言权"

### 第三章 · 做到什么程度(4-5 页) ⭐ 答辩数据硬通货

**P12 关键技术细节(精选 3 个)**

**P13 测试集与评测方法学** ⭐⭐⭐
- 标题:**100 条 = 50 精标 + 50 变体**
- 左侧:精标分布表(骚扰/歧视/无关 × 高/中/低)
- 右侧:变体策略(同义改写 15 / 细节扰动 12 / 干扰句 10 / 要件边界 8 / 长文本扩展 5)
- 强调:**17 条挂真实司法判例 + 6 条挂法条 + 27 条规则派生**
- 列出锚点判例:严女士案 / 韩坤案 / 林某案 / 周某案 / 陈某 vs 杨某案 / 谷歌同工同酬案

**P14 准确率数据**(等评测跑完填) ⭐⭐⭐

- 下方四个分等级召回率(高/中/低/无风险)
- 右侧 4×4 混淆矩阵热力图(用风险等级配色)

**P15 鲁棒性数据**(等评测跑完填)
- 5 类变体的稳定性表格
- 强调"语言改写/细节扰动后准确率仍 XX%,产品不靠表面词识别"

**P16 真实判例锚定示例**
- 选 3 个最有冲击力的案例:严女士入职孕检案(浦东法院 2023)、韩坤哺乳期被辞案 (2009)厦民终字第2188号、周某强制猥亵案(芜湖检察院 2023)

## 五、答辩流程建议(15-20 分钟)

## 六、做 PPT 时的"避雷清单"

1. ❌ **别用纯黑底**:暖紫主题撑不住黑底,会显得阴沉
2. ❌ **别堆术语**:技术页里"要件""召回优先"这些词,**每页最多出现一次**,其他用白话
3. ❌ **别用红配绿对比**:用我们定的"风险等级配色"是合法的,但其他地方不要乱配
4. ❌ **别让单页超过 7 个要点**:超过就拆页
5. ❌ **代码截图字号要够大**:演示页代码 18pt 以上,远的评委看得见
6. ✅ **每页有一个明确的"视觉焦点"**:大数字 / 大图 / 大引用 选一个,不要混搭
7. ✅ **现场演示有备用截图**:网络抽风时切回截图,别白屏
