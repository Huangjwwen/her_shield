# P4 · 一条断裂的链【0:45 → 1:35 / 50 秒】

> 「先来看三个数据。
> **第一**,智联招聘 2026 调查报告:**60.9% 的求职女性曾被问到婚育情况**。

>
> 这三个数字背后,是**一条断裂的链**。我们发现,女性遭遇职场不公时,会被卡在 **5 个层级**:
> **认知层** — 70% 女性遭遇歧视却不知违法,法律条文晦涩,信息碎片化;
> **情绪层** — 愤怒、羞耻、害怕交织,缺乏即时低门槛的情绪承接渠道
> **证据层** — 不清楚保存什么，怎么保存,事后补救往往证据已灭失
> **行动层** — 担心报复、不了解流程、律师费高昂,缺乏可操作指南
> **归属层** — 没有同伴，受害者易陷入孤立感
>
> **任何一环卡住,整条维权链就断了。** 我们要做的,就是**把这条断裂链重新接上**。」

# P10 · 言行雷达工作流详解【3:50 → 4:40 / 50 秒】

> 首先是言行雷达，从工作流开始进行讲解，它有 5 大设计亮点:
>
> **①** **召回优先门控**（工作流处理完图片后就来到这个节点） —— 遵循"拿不准就判涉及"原则,100 条测试集**无风险样本 100% 准**,不漏判。
>
> **②** **事实标注与风险等级映射分离** —— 这是我们方法学的核心 —— **LLM 只标要件状态**(行为是否与性有关、是否违背意愿等),**风险等级由代码节点确定性映射**，而不是让大模型凭感觉打等级。
>
> **③** **法条 + 类案双 RAG** —— 调得理 API 实时检索,**每条引用挂法院 / 案号 / 年份**。
>
> **④** **强制深度分析按钮** —— 用户认为误判,可一键跳过门控到提取案情要素节点，直接进行之后的分析。
>
> **⑤** **三级话术 + 温暖回应** —— 可直接复制的委婉 / 坚定 / 正式 三档话术;温暖回应**先接情绪再讲法律**。」
